# ASCII Christmas
Один автономный HTML-файл для GitHub Pages.

1. Создайте отдельный публичный репозиторий `ascii-christmas`.
2. Загрузите `index.html` в корень.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ascii-christmas/`.

Без сборки, сервера, токенов и сторонних библиотек.
